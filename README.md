## 2. このアイデアはどこから生まれたか

### 2-1. きっかけとなった体験・感情

・既存のSNSは必要以上の情報が流入し、それに伴うSNS疲れという関連意見をメディアでもよく見るようになった。

・SNSではなく日記帳を購入して記録する人々が一定数おり、密かなトレンドになっているとニュースで見た。

・幼少期に女子が交換日記や自由帳でいつも遊んでいたのと、現在でもシール帳やアルバムに書き込んで記録することが
女性を中心に根強い人気があることからSNSにも転用できるのではないかと考えた。

・X(旧Twitter)を毎日利用している側から言えば、過剰なインプレッション稼ぎや荒らし行為、偽情報の流布、
無秩序かつ公序良俗に反するような投稿の氾濫に辟易としていた。

- いつ

- どんな気持ちになったか

### 2-2. なぜそれが「気になった」のか

- 自分の性格：無秩序な環境が許容できない
- 過去の経験：既存のSNSを利用していて不満が積もっていた

### 10-3.キャッチアップ不足の懸念

キャッチアップ不足の段階では以下の懸念点があります。
1. **完成までのハードルが高い**
使用する言語やフレームワークが異なるため、キャッチアップにかかる時間は個人差があるものの、一定の時間を要することが予想されます。
2. **Issueの見積もりが難しい**
「どこまで理解していて、何が分からないのか」「調査にかかる時間」などが不明瞭な場合、開発期間内に完了することが難しくなってしまいます。

例えば、最近注目されているReactやNextについて。
Reactについては**本リリース後に組み込む方向で検討**するのが良いかと考えています。
その後、React単体のキャッチアップを行い、アプリに組み込む技術的な検証をした上で、組み込むかどうかを判断する形が理想かもしれません。
